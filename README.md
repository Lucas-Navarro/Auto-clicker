<h1>Auto clicker/ ClickerPoint</h1>
<p>Crie este app para ajudar meu pai a trabalhar pegando ofertas de site automaticamente</p>
<p>Já que ele depende disso para trazer renda para nossa casa</p>
<h2>Bibliotecas utilizadas:</h2>
* Pyautogui: utilizado para automatizar clicks e buscar imagens
* theading: Como ele roda várias vezes seguidas para pegar ofertas é bom para não travar o app
* time: Utilizado para dar pausa entre as rodagens que fazer
* tkinter: Utilizado para fazer uma interface fácil e intuitiva para rodar
